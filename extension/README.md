# SyncPress 扩展

当前版本：v1.0（内部版本 1.0.0）。本目录是无需构建即可加载的 Chrome / Edge Manifest V3 扩展。

在扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择本目录，然后点击工具栏图标打开排版工作台。普通使用不需要 Node.js、API Key 或本地服务。

完整说明见 [README](../README.md)、[隐私与权限](../PRIVACY.md)、[准备包格式](../docs/packages.md)、[第三方声明](../THIRD_PARTY_NOTICES.md) 和 [版本记录](../CHANGELOG.md)。
