# 可选集成

## 本机准备包服务

`bridge-client.js` 支持读取用户主动选择的连接文件。文件仅允许 `http://127.0.0.1:端口` 回环端点与规定格式的令牌，并按协议读取、逐文件验证准备包。

本仓库包含通用客户端和准备包格式，不附带服务端、业务数据或可用令牌。普通导入、排版、导出和平台填入不需要本机服务。不要提交真实 `connection.json` 或从其他电脑复制的令牌。

接口、数据格式与配置统一使用 `DRAFT_HELPER_*` 命名空间；开发自己的本机服务时，应按客户端的协议和完整性校验接入。

## 网站内嵌工作台

本仓库交付独立浏览器扩展和命令行工具，不包含宿主网站服务。网站集成应单独处理扩展 API、稿件存储、来源证明与消息来源校验。
